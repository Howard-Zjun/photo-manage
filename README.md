# 图片管理与分享系统

## 项目简介

本项目是一个基于 Spring Boot 的毕业设计，面向个人用户提供照片上传、内容分享与社交互动能力。用户可以发布包含图片、文字和标签的动态，浏览好友或公开内容，并通过点赞、评论和标签分组等方式管理自己的个人空间。

项目采用服务端渲染页面，后端负责用户认证、业务数据管理和图片资源存储。

## 主要功能

- 用户注册、登录与退出；使用 Redis 保存登录令牌。
- 首页动态流浏览，支持分页展示与访问权限过滤。
- 发布图文动态，支持上传图片、填写标题、正文和标签。
- 动态详情查看、点赞与评论。
- 个人空间管理：查看自己发布的内容、控制动态展示状态、删除动态。
- 好友关系管理：查看和删除好友。
- 标签分组管理：创建标签、维护好友与标签的关联、为动态设置可见标签。
- 个人资料查看与编辑。
- 图片上传与读取：使用 MongoDB GridFS 保存图片文件。
